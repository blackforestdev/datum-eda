### Q4 concrete repair: Zone origin and copper arcs

**Observed gaps and inherited requirements.** UVT §2.2.4/5/16 and the class
matrix require one authored Zone identity, all-island Object qualification and a
physical Run through zone copper; disconnected copper is not one Run. The native
format §5.2.1 and `substrate/zone_fill.rs` already define revision-bound Filled
polygons and no copper for missing/Unfilled/Stale/Unsupported evidence. A polygon
in `islands` is not necessarily a separate electrical island: adjacent cutout
slabs must be joined by actual contact. `board/net_graph.rs` and zone-aware route
selection currently use authored zone polygons/endpoint graphs; neither proves
current-fill complete components. Do not reuse that approximation as S5A proof.

UVT's Track row explicitly requires straight **and curved copper** section
qualification; the separate line/arc/outline graphic row cannot substitute.
`board/board_types.rs::Track` has only from/to, width, layer and Net/UUID.
`export/copper.rs` emits a straight chord; native GUI projection in
`gui-protocol/src/lib.rs` emits `[from,to]`. `ir/geometry.rs::Arc` is a rounded
center/radius/angle graphic representation, not an existing exact authored Track
midpoint. PCB tool contract §4 and its omitted-tools ledger require arcs as a
Track segment attribute, not a new object/tool. These facts establish a source
geometry gap as well as query exposure; no new routing campaign is justified.

**Recommended Zone behavior (new product clarification Z1).** Keep Object(Z)
and its all-island marquee rule unchanged. A direct copper hit may request the
engine's current physical component through the hit on Z. The transient hit
point is an acquisition input only. The engine returns an opaque, revision-bound
component qualifier with source Zone/occurrence reference and canonical copper
basis; it is a derived locator, never a new authored UUID or saved coordinate.
GUI stores it with Run(origin Z), not a renderer island index. Canonicalization
ignores polygon ordering, winding and adjacent decomposition seams. A boundary
hit or keyboard/menu request lacking a copper hit acquires a Run only when Z
resolves to exactly one physical component; otherwise refuse that Run request,
explain “Choose copper in the desired connected region”, and preserve the prior
subject/focus. Hidden/filtered Z cannot originate acquisition. A visible eligible
origin acquires the entire component even if other members are hidden/filtered.

The component includes all connected tracks/vias/pads and current-fill portions,
including other Zones where their copper genuinely connects. Source membership
counts each authored Zone once; two disconnected Runs can reference the same Z
with different derived component qualifiers. Their Run projection includes only
participating copper and its component perimeter, preserving layer material,
without an accent on Z's disconnected region or a false connecting boundary.
Object(Z) and Global Net still project the whole resolving Zone. Inspection
states “Zone Z: connected region of Run; complete Zone has other regions” when
applicable, with source count and component geometry separately disclosed.
No independently selectable island, new subject kind or truncated membership.
This distinction needs explicit PM026/UVT/Rendering Book reconciliation; it is
not silently derived from the existing whole-Zone Object presentation clause.

**Recommended revision law (new product clarification Z2).** For a zone-qualified
Run, retain the prior resolved Zone copper region and basis as derived state.
After a successful new revision, intersect that region with current copper of
the **same surviving source Zone occurrence**, then identify successor physical
components. Exactly one component with positive-area overlap: rebind qualifier
and re-derive its complete membership (including newly joined branches or merged
regions). Zero successors, multiple successors after a split, lost source Zone,
or changed occurrence: dissolve and report “Run origin region no longer resolves
uniquely”; undo does not resurrect it. Do not choose the largest overlap, first
array element or nearest point. Reordered/decomposed equivalent fill preserves
the component; a disjoint moved region requires reacquisition. If prior basis
cannot be supplied, return authority unavailable, not a guessed successor.
Unsuccessful/stale authority preserves explicitly stale prior state under the
query contract rather than proving deletion. A successfully resolved non-Filled
Zone proves no copper origin and dissolves its Run with disclosed fill state.
A track/via-origin Run still follows the existing surviving authored-origin law.

For initial non-Filled zone acquisition, Object inspection remains available;
Run request is refused with the precise missing/Unfilled/Stale/Unsupported reason,
prior selection unchanged and no implicit fill/write. Explicit Select Net can
still acquire complete logical Zone membership when Net authority is available;
no physical copper is fabricated. Advancing click depth must not disguise a
failed Run request as successful Run or automatic Net acquisition. Outline hits
in an empty gap behave like the ambiguous boundary case above. The lifetime and
projection choices Z1/Z2 require owner ratification **after independent review**.
Their consequence is deliberate cancellation on ambiguous split/disjoint move,
rather than silently following one disconnected region. Persisted island IDs,
coordinate origins and union-of-islands selection are rejected alternatives.

**Recommended Track repair (encoding T1; inherited user behavior).** Add
`arc_midpoint: Option<Point>` to Track; absent/omitted means existing straight
segment and serializes exactly as before. Present means the unique directed
circular arc from `from` through the authored midpoint to `to`. All three anchors
are exact integer nanometers; midpoint is the authored on-curve anchor, not a
chord midpoint or an angle-derived sample. Net, layer, width and UUID remain the
existing Track fields. Reject coincident/collinear triples, zero/negative width,
invalid layers and unrepresentable arithmetic through typed preflight, with zero
partial writes. Full-circle copper is represented by multiple valid Track
sections, not this three-point encoding. Updating straight↔arc preserves Track
UUID and journals exact replacement geometry. Extend existing typed native
Track create/set builders, not a separate arc writer or tool. No new manual route
interaction or automatic router generation is included.

One engine-owned geometry helper derives directed sweep, analytic occupied
copper and deterministic projection from these anchors. Contact uses the actual
swept-width curve, pad shape, via span and current filled polygons, including
interior/tangent contact on compatible layers; never the chord or renderer
samples. Use checked arithmetic and existing unit/export precision; return a
typed range failure instead of overflow/guessed connectivity. Screen flattening
is a derived display calculation only. U1 gets exact qualification anchors plus
source UUID, while rendering gets the same curve's generated path. Copper CAM
emits the actual directed circular interpolation, or refuses an unrepresentable
curve under existing export precision rules; it cannot silently emit a chord.
No new numerical performance or geometric-error budget is ratified by this plan.

All consumers assuming straight geometry must either use this helper or reject
the arc case explicitly before work. Selection membership, native projection,
connectivity and clearance DRC are required supported consumers. Existing
straight-only route proposal/preflight kernels may refuse a board containing
relevant arcs with a source-bound unsupported diagnostic; they cannot produce a
successful chord-based route. Bounded zone fill must likewise diagnose unsupported
foreign-arc obstacle handling unless its existing conservative obstacle-envelope
policy is correctly extended. Same-Net/no-thermal fill fixtures do not require
new thermal or general-pour algorithms. These safeguards preserve older straight
behavior without claiming complete arc-aware routing/fill support.
