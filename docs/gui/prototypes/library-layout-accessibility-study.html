Datum · Library Surfaces Study — layout and accessibility

◐ OPEN CANDIDATE · SURFACE-S04 · not approved, not implemented, not product-ratified

Normal, narrow, tiled, Zoom, Stage, Terminal and keyboard-focus frames (frame L-J). This page is part of a three-page candidate study; the index, frame legend and frame → clause map are in library-surfaces-study.html. Nothing here selects a presentation, a policy, a threshold or an implementation successor; the owner's SURFACE-S05 disposition is still ahead.

Every pool, object, manufacturer, MPN, identifier, hash, dimension and value drawn here is an illustrative synthetic first-party example. None is an approved library asset, a real manufacturer part, a standards-derived number, a real digest or a production seed. Where a number appears it is a made-up example that shows where a value is displayed and compared, not what it should be. Pixel sizes and font stacks are mockup placeholders; tokens govern.

Pad shape note. Current native library apertures are Circle and Rect. Every land in this study is therefore drawn as a plain square-cornered Rect. The Rendering Book's rounded-rectangle pad direction is not materialized by a native aperture today; a rounded rectangle is shown only where it is explicitly marked unsupported (L-B7, L-D). That difference is shown, not resolved.

The library projection inherits the one-window recursive pane tree, focus-owned Inspector, pane-local output-only Console, Zoom and Full-Screen Stage, with the Terminal as its own surface. No preset or detached window is introduced. The focused pane carries the accent frame and the word FOCUS with a square glyph; map and relationship correspondence and every status use text and glyphs as well as colour. How pool, kind, Navigator and Inspector are reached in a narrow window is a candidate presentation. Static frames: keyboard and assistive-technology qualification require the ordinary application.
