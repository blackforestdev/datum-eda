The compound mark

Flick toward Align, then toward a direction — the two strokes join into one bent gesture (an inverted "L"). Because the sub-wheel always spawns in the same place relative to the parent, the whole shape becomes one memorized flick, drawn without the menu ever showing. That's the exponential speedup Kurtenbach & Buxton measured.

Spawn-in-place, and clamp inward at edges

A submenu opens as its own radial at the flicked wedge's location, the parent fading/blurring behind it — so the gesture flows outward and the path stays constant. Near a viewport edge or a narrow pane the whole wheel repositions inward (clamp-inward, the Blender model) so it never spills off-screen and the angular gesture vocabulary stays intact. Sub-wheels are content-sized — the live Align sub-wheel is 3-wide (Horizontal / Vertical / Distribute), not a fixed cardinal count.

Two modes, one gesture

Hold ~280 ms and the labelled wheel draws — the novice path. Flick before the threshold and the wheel never draws; only the mark-trail renders as the command commits — the expert path, eyes on the board. The same gesture serves both, so novices become experts without relearning. The 280 ms is a tunable interaction default, not a performance figure.

On one component, the cardinals differ

This demo is the multi-select wheel, where Align is a live sub-wheel. On a single component the canonical cardinals are N Rotate · E Properties · S Delete · W Flip (Move is a secondary at NE), and Align / Distribute lives in the overflow list, not a sub-wheel — per menu_model.json, the ratified source. Delete is always cardinal; a destructive verb never sits on a diagonal.
