Datum · Library Surfaces Study

◐ OPEN CANDIDATE · SURFACE-S04 · not approved, not implemented, not product-ratified

Candidate frames for the Library Surface Contract — SURFACE-S03 Draft in docs/gui/DATUM_GUI_PRODUCT_SPEC.md, across the eight Pool kinds — Unit, Symbol, Entity, Part, Package, Footprint, Padstack, PinPadMap. Models, metadata, provenance, basis and findings are linked detail surfaces; there is no ninth kind. Combined independent review (SURFACE-REVIEW) and the owner's disposition (SURFACE-S05) are still ahead. Nothing here selects a ranking, pool precedence, writable target, warning-or-block policy, generator family, standards basis, process default or implementation breadth.

Every pool, object, manufacturer, MPN, identifier, hash, dimension and value drawn here is an illustrative synthetic first-party example. None is an approved library asset, a real manufacturer part, a standards-derived number, a real digest or a production seed. Where a number appears it is a made-up example that shows where a value is displayed and compared, not what it should be. Pixel sizes and font stacks are mockup placeholders; tokens govern.

Pad shape note. Current native library apertures are Circle and Rect. Every land in this study is therefore drawn as a plain square-cornered Rect. The Rendering Book's rounded-rectangle pad direction is not materialized by a native aperture today; a rounded rectangle is shown only where it is explicitly marked unsupported (L-B7, L-D). That difference is shown, not resolved.
