Candidate frames for the Library Surface Contract — SURFACE-S03 Draft in docs/gui/DATUM_GUI_PRODUCT_SPEC.md, across the eight Pool kinds — Unit, Symbol, Entity, Part, Package, Footprint, Padstack, PinPadMap. Models, metadata, provenance, basis and findings are linked detail surfaces; there is no ninth kind. Combined independent review (SURFACE-REVIEW) and the owner's disposition (SURFACE-S05) are still ahead. Nothing here selects a ranking, pool precedence, writable target, warning-or-block policy, generator family, standards basis, process default or implementation breadth.

Every pool, object, manufacturer, MPN, identifier, hash, dimension and value drawn here is an illustrative synthetic first-party example. None is an approved library asset, a real manufacturer part, a standards-derived number, a real digest or a production seed. Where a number appears it is a made-up example that shows where a value is displayed and compared, not what it should be. Pixel sizes and font stacks are mockup placeholders; tokens govern.

Pad shape note. Current native library apertures are Circle and Rect. Every land in this study is therefore drawn as a plain square-cornered Rect. The Rendering Book's rounded-rectangle pad direction is not materialized by a native aperture today; a rounded rectangle is shown only where it is explicitly marked unsupported (L-B7, L-D). That difference is shown, not resolved.

L-HPlace Component — focused search on the captured schematic: project Parts and shipped Symbols ○ TARGET · not delivered● CURRENT · bounded, at recorded scope only◐ OWNER CHOICE · S05

Normal placement is one readable Place Component picker opened directly on the schematic being edited: the target document and occurrence are captured when it opens and the search is focused immediately — no source step, no path, no snapshot choice, nothing to configure first. It searches exactly two explicit result kinds. Part — a complete declared Part available in this project — retains its qualification and its symbol + footprint / pin-pad map. Part eligibility is stated by the existing engine checks — the complete declared default graph — and whether a non-approved or unknown-basis Part warns or blocks stays the S05 owner disposition. L-KUnresolved transfer component — source-qualified resolution: assign a compatible Part or author one from the placed Symbol ○ TARGET · not delivered◇ SYNTHETIC

The retained root-schematic transfer review (trigger context: schematic-pcb-connectivity-revision-study.html#Q1) can meet a project whose placed symbols have only saved Unit / Symbol definitions — no Entity, Part, Package, Footprint, Padstack or PinPadMap exists yet. Such a component is unresolved for transfer and is never guessed: no component, pin map or footprint is invented, no redraw or new project is suggested, and nothing external is imported or adopted silently. Each unresolved row names its reference and value and carries an explicit Resolve… action. Resolution is source-qualified: a compatible Part must reference this placed Symbol's exact existing Unit / Symbol identity — a same-looking Part built on a different Unit or Symbol is stated incompatible, never offered as a near match. Where a compatible complete Part exists, the existing explicit Assign Part flow binds it through the shared Preview / Proposal / human-acceptance path, preserving the placed symbol's identity, pins, pose and wiring. Where none exists, the flow states exactly which definitions are missing and offers the existing Library editors (L-B3…L-B8, L-G) to author them from the placed Symbol's own Unit / Symbol, keeping the target reference visible while authoring. Return to assignment and transfer retry are explicit; returning restores the exact original placed symbol and schematic occurrence. Committing Library definitions is the purpose of this recovery, so Library-only revisions made along the way never make the flow stale: on return the original placed-symbol preimage, its project root, its pane / document / occurrence and source-definition compatibility are revalidated unchanged. A genuinely changed, missing or rebound placed target, or a switched project or view, refuses and restarts truthfully — stated as meaningful names and next actions; the revalidation guards are internal. Cancelling or navigating away makes no assignment and no new design edit, and never rewinds a separately committed Library edit; a pending uncommitted draft or running authoring step must be finished, cancelled or awaited explicitly — never discarded silently. Every name, value and count is synthetic.
