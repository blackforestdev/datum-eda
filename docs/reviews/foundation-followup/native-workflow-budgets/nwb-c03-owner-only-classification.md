# NWB-C03 owner_only classification

NWB-C03 ("owner ratification") ratifies PM051 numeric budgets — which proposed
figures become blocking thresholds for acceptance. PM059 holds that "no missing
measurement, tolerance, license or qualification is supplied by either manager or
owner approval," so this decision is classified `owner_only`: it never routes to
the appointed manager and stays a first-class, visible owner gate
(`decision_maker = project_owner`, `owner_input_required = true`) even under the
active standing appointment. This record CLASSIFIES the boundary; it does not
decide it. The staged NWB-C03 ratify disposition remains armed for the owner.
