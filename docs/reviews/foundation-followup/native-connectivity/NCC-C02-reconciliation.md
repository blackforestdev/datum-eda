## §B — Behavior specification (9 behaviors; INHERITED vs DECISION tagged; topology+journal rule each)
Topology delta = change to the derived `SchematicConnectivityGraph` (nets/members/pin_attachments/port_links/diagnostics). Journal delta = authored-mutation transaction(s) only (check/resolve are not authored mutations — C01 §C.3). Identity law (PM053 spine): authored identity is distinct from recomputable geometry; identity survives quantize.
**Current-vs-target API note:** `SchematicConnectivityGraph` is the spec §3 TARGET shape; the shipped engine currently exposes the same graph intent via `SchematicNetInfo` / `HierarchyInfo` / `ConnectivityDiagnosticInfo` (spec §3 :39-43). The per-behavior topology deltas reference the target graph (fine for a behavior draft); when a future implementation step RUNS the §E proof scenarios, they assert against those current read surfaces that carry the same intent, not a not-yet-existing struct.
**Finding-1 convention (per audit):** each DECISION recommendation below separates the **INHERITED FLOOR** (already governed; not open to ratify) from the **OPEN CHOICE** (what NCC-C03 actually ratifies), so the owner's C03 surface shows only what is genuinely open.

1. **Endpoint-on-segment T-junction** — **DECISION (D1).** Spec §4.1 (:85-88) governs the RESOLUTION (a junction or shared endpoint connects) but is silent on the native authoring GESTURE. **INHERITED FLOOR:** never implicitly create a junction — a crossing/touch does not auto-connect absent an explicit junction or shared endpoint (spec §4.1 :89-91; this resolution-rule gloss INFORMS, does not dictate, the gesture). **OPEN CHOICE (→ NCC-C03):** (b) explicit-junction-everywhere vs (c) hybrid (auto only at an authored endpoint, explicit elsewhere); option (a) KiCad-like auto-junction-at-crossing is DISRECOMMENDED — it would let imported-format behavior set native gesture policy (authority-review §969). **Recommendation:** (c) hybrid. Topology: on an authored junction, +junction node, nets merge (two → one survivor per PM053 merge law). Journal: one authored transaction (add-junction + the connecting wire edit).
2. **Crossing without junction** — **INHERITED.** Spec §4.1 :89-91: crossing wires are NOT connected without an explicit junction/source-format mark. Topology: no change (two nets stay distinct). Journal: the wire edit only; no implicit merge. No decision.
3. **Explicit join (junction at a crossing)** — **INHERITED rule, DECISION gesture (D1).** The RESULT (explicit junction joins) is spec §4.1; the native GESTURE to place it is D1. Topology: nets merge at the authored junction (deterministic survivor, PM053). Journal: one authored add-junction transaction.
4. **Off-lattice pin attachment** — **DECISION (D1, part of D3's contract).** A pin is at a fixed symbol-relative coordinate that may be off the active grid. **INHERITED FLOOR (PM023 / UVT §3):** object-snap to the pin overrides grid within the eligible screen-radius; the committed coordinate is the pin's exact nm, not a quantized value. **OPEN CHOICE (→ NCC-C03):** the pin-attachment RULE — a wire endpoint attaches to the pin by exact pin coordinate regardless of the active grid. **Recommendation:** attach by exact pin coordinate. Topology: +PinAttachment{net, component, gate, pin} (spec §3 :61-66; `gate: Option<Uuid>`). Journal: one authored wire transaction; no re-snap of the pin.
5. **Connected move + quantize** — **DECISION (D3).** When a connected wire/symbol moves (and may quantize to grid), formation may re-run (geometry changed) but identity must survive. **INHERITED FLOOR (not open to ratify):** identity SURVIVES quantize — nets keep their uuid; quantize NEVER changes identity (UVT §3.3 / PM053 identity-survives-quantize); PM023 exact committed nm args; object-snap overrides grid; no implicit re-snap on display change; "switching a reading must neither move geometry nor implicitly quantize it" (authority-review §691). **OPEN CHOICE (→ NCC-C03):** formation-re-run TIMING — whether/when a connected move that breaks or forms a touch re-runs formation. **Recommendation:** formation re-runs only on an authored geometry commit, not on display re-snap. Topology: members move between nets ONLY by authored formation change, never by quantize alone. Journal: one authored move transaction; display/units change = zero journal.
6. **Rename / identity** — **INHERITED.** PM053 (:191-192): display rename PRESERVES identity; a label edit changing electrical groups follows RECORDED transitions; names are attributes not identities (spec §5 :142). Merge records deterministic survivor; split preserves anchored-group identity (PM053 :193-194, PM000D §1007). Topology: net.name changes but net.uuid stable (rename), or recorded transition (group change). Journal: one authored label/rename transaction; read/reopen NEVER allocate identity (PM053 :191).
7. **Wire-chain Finish/Escape** — **DECISION (D2).** Spec/authority-review §970: UNANSWERED which clicked segments are committed and what Escape discards. **INHERITED FLOOR (§970 required disposition, not open):** Escape discards the uncommitted preview with ZERO journal effect (no-write cancellation). **OPEN CHOICE (→ NCC-C03):** Finish commit-GRANULARITY — that Finish commits the whole chain as ONE authored transaction, and exactly which clicked vertices are committed when (the §970 "unanswered transaction boundary"). **Recommendation:** each committed vertex extends an uncommitted PREVIEW; Finish (double-click/explicit) commits the whole chain as ONE transaction. Topology: on Finish, +wire segments + any formation; on Escape, none. Journal: Finish = one transaction (start→vertices→finish); Escape = zero.
8. **Undo / redo** — **INHERITED (compensating-journal law).** PM000D (§1006) + authority-review §966: undo restores domain values via a NEW append-only compensating transaction that ADVANCES object revisions — NOT by rewinding model history; a blanket "model_revision reverts" is incorrect. Topology: the graph re-derives from the restored authored data (identities stable). Journal: +1 compensating transaction (not a decrement). Assert restored domain values + stable identities SEPARATELY from the new transaction/object-revisions/model-hash (authority-review §966).
9. **Reopen** — **INHERITED.** Output graph is DERIVED and byte-stable given identical authored data (spec §3 :77-78); read/cache/reopen NEVER allocate identity (PM053 :191); canonical writes/replay retain all recorded identities (PM053 :200-201). Topology: identical graph after reopen. Journal: zero (reopen authors nothing). Test after reopening (authority-review §966 required-evidence).
